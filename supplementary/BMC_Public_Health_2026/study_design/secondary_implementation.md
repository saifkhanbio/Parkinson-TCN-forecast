# Prespecified incidence and GCC replication

This execution specification extends the locked, already evaluated Saudi prevalence experiment to Saudi incidence and prevalence/incidence in Bahrain, Kuwait, Oman, Qatar, and the United Arab Emirates. The eleven new experiments are secondary replications. They do not replace the Saudi prevalence primary result or redefine its joint success criterion. Jordan remains a regional donor, not a GCC evaluation target. Outcomes are GBD modeled age-specific rates; population weighting is a sensitivity analysis, not age standardization.

## Identical estimands and chronological decisions

Each target/outcome uses the same 11 ages, both sexes, eight input years, horizons one through five, 14 underlying families, candidate grids, cold-start defaults, loss, five TCN seeds, and two-coefficient adaptation as the locked primary implementation. Candidate origins 2003–2013 permit hyperparameter selection only from fully completed five-year windows available at each issuance origin. The TCN tuning seed remains 11; reported historical and evaluation forecasts average all five fixed seed log changes before estimating the sex-specific correction. No fitted encoder or prediction head is adapted.

The default donor pool comprises all six other countries, excluding the target in both sexes. Pooled controls include all seven countries. The target country is set explicitly in a copied configuration. Each worker filters the **actual requested outcome and years through its origin before** relabeling a copied internal panel `prevalence`, solely to reuse immutable model implementations whose internal channel name is fixed. Public forecasts, scores, intervals, and metadata restore the actual outcome. This adapter does not mix prevalence observations into incidence models. The existing prevalence-implied origin population is used identically for both outcomes' sensitivity weights; it is never a predictor.

Local and non-neural family champions are selected separately by sex from eligible development origins 2009–2013. Origins 2014–2018 form the reliability evaluation; the 2018/horizon-five endpoint is a view of the same forecasts, not an additional fit. Results report all 14 families and two explicit champion views. A secondary endpoint can describe whether all four strict comparisons favor the TCN, but cannot substitute for the primary Saudi prevalence conclusion. No independent-cell significance tests or causal interpretations are introduced.

## Joint intervals and preserved point predictions

Historical selected forecasts at 2003–2013 build the same complete 110-coordinate residual blocks (sex × age × horizon). Blocks use log truth minus log point and coordinate-wise arithmetic-mean centering. At each evaluation origin only fully verified blocks enter, yielding 7–11 blocks. The 80 banks per target/outcome include 14 families and two champion histories. A champion bank stitches the currently selected male/female families by common past origin, preserving each family's historically selected settings.

Central 50%, 80%, and exploratory 95% intervals use linear quantiles independently on log-rate draws and exponentiated rate draws. Original point forecasts remain distinct from predictive medians. GBD supplied bounds do not enter these predictive intervals. Coverage, width, interval score, and WIS 50/80 and 50/80/95 follow the stage-4 implementation. Sparse, dependent blocks provide no exact coverage guarantee; undercoverage is reported without retuning this experiment.

## Execution and resume integrity

`scripts/run_secondary.py --workers 12 --device cpu` uses one shared spawned CPU process pool across all eleven experiments; each worker has one numerical thread. CPU execution retains comparability with the original Saudi models. Explicit CUDA execution is supported with a separate, bounded neural pool and cannot silently fall back to CPU. The resource benchmark is copied to the run. Device changes constitute a different experiment.

Each fit job has a canonical target/outcome/origin/model/seed/device identity, a saved payload, optional model checkpoints, and SHA-256 completion hashes. A failed invocation can resume with `--resume` only when code, tests, configuration, source, prior manifests, numerical environment, resources, and device match. Completed jobs and phase artifacts are verified before reuse; changed artifacts fail closed. Unfinished jobs can be rerun. Existing completed runs are verified without refitting.

The phases are candidate fitting, candidate ledger commitment and restricted scoring, frozen decisions, selected historical/evaluation fitting, all eleven issued point/interval ledgers, and only then final scoring. Consequently, every experiment's forecasts and intervals are committed before any new final-period comparison is computed. Each trial has 16,940 historical selected forecasts, 8,800 evaluation point rows (7,700 underlying plus 1,100 champion views), 52,800 interval rows, 79,200 joint draws, and 17,600 WIS rows. Each has 157 unique TCN source fits: 88 candidate fits, 44 additional historical ensemble seeds, and 25 evaluation fits. Five-seed ensembles are retained even if a documented fit fallback occurs.

Outputs reside in `results/secondary_v1/trials/{ISO3}_{outcome}/`. Original Saudi prevalence results are hash-verified and referenced unchanged. Synthetic adapter, selection, cache, and chronology tests are required before production. The main runner refuses stale test hashes. Independent verification and reporting are separate from fitting.
